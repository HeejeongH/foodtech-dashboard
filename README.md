# 서울대 푸드테크 센터 · 월드푸드테크협의회 대시보드

서울대학교 푸드테크 센터의 3개 교육과정 참여자와 월드푸드테크협의회 회원·행사·발표를 관리하는 인터랙티브 대시보드입니다.

## 📂 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 대시보드 프론트엔드 전체 (HTML + CSS + JS 단일 파일) |
| `queries.sql` | 대시보드가 호출하는 26개 named SQL 쿼리 |
| `schema.sql` | 워크스페이스 데이터베이스 스키마 (13개 테이블 + 3개 뷰) |
| `README.md` | 이 파일 |

## 🏗️ 아키텍처

이 대시보드는 **AgentDB (PostgreSQL 기반) 워크스페이스**의 인터랙티브 뷰(interactive view)로 실행됩니다.

```
┌─────────────────────────────────────────────────┐
│  index.html (프론트엔드)                        │
│  ─ 대시보드 · 교육과정 · 사람 · 행사 라우팅     │
│  ─ 클릭하면 window.agentdb.executeQuery(...) 호출│
└─────────────────────────┬───────────────────────┘
                          │ Bridge SDK
┌─────────────────────────▼───────────────────────┐
│  Named SQL Queries (queries.sql)                │
│  ─ 서버에 등록된 26개 쿼리                      │
│  ─ 프론트엔드는 이름과 파라미터로만 호출        │
└─────────────────────────┬───────────────────────┘
                          │
┌─────────────────────────▼───────────────────────┐
│  PostgreSQL 워크스페이스 DB (schema.sql)         │
│  ─ 13개 테이블 + 3개 편의 뷰                    │
└─────────────────────────────────────────────────┘
```

## ✏️ 편집 및 재적용 방법

### 방법 1: 워크스페이스 UI에서 직접 편집 (권장)
1. 워크스페이스에서 대시보드 인터랙티브 뷰를 엽니다
2. 우측 상단 "편집" 또는 코드 아이콘 클릭
3. 파일을 브라우저에서 수정하고 저장

### 방법 2: 로컬에서 편집 후 재업로드 (Git 사용)
1. 이 파일들을 GitHub 저장소에 커밋
2. 로컬에서 편집기(VS Code 등)로 편집
3. 워크스페이스에 다시 업로드:
   - `index.html` → 인터랙티브 뷰의 파일로 업로드
   - `queries.sql` → 각 쿼리 블록을 뷰의 "Query" 관리 화면에서 upsert
   - `schema.sql` → 스키마 변경이 필요할 때만 관리자가 실행 (⚠️ 기존 데이터 손실 주의)

### 방법 3: 에이전트에게 요청
워크스페이스 채팅에 "index.html의 이 부분을 이렇게 바꿔줘" 라고 요청하면 자동으로 적용됩니다.

## 🌐 GitHub 연동 팁

현재 AgentDB 자체는 GitHub와 자동 동기화 기능은 없지만, **수동 동기화 워크플로우**를 만들 수 있어요:

1. 이 저장소를 GitHub에 push
2. 편집이 필요할 때:
   - GitHub에서 편집 (또는 로컬에서 편집 후 push)
   - 편집된 `index.html`을 워크스페이스로 다시 업로드
3. 반대 방향 (워크스페이스에서 편집 후 GitHub에 반영):
   - 워크스페이스에서 파일 다운로드
   - 로컬 저장소에 덮어쓰고 커밋 → push

## 🔗 주요 라우트

`index.html` 안에서 단일 페이지 라우팅으로 처리됩니다:

| 라우트 | 설명 |
|---|---|
| `dashboard` | 메인 대시보드 (기본 진입점) |
| `programs` | 교육과정 인덱스 |
| `program?program=<name>` | 특정 교육과정 상세 (기수별 참여자) |
| `people` | 전체 사람 목록 |
| `person?person_id=<id>` | 사람 프로필 (교육 · 발표 이력) |
| `wftc?status=<state>` | 협의회 회원 목록 (상태 필터) |
| `non_members` | 가입 권유 대상 리스트 |
| `events` | 전체 행사 목록 |
| `event?event_id=<id>` | 행사 상세 (발표자 명단) |
| `event_new` | 행사 등록 폼 |
| `presentation_new` | 발표 등록 폼 |

## 📌 주의사항

- 프론트엔드에서 raw SQL을 직접 실행할 수 없어요. 새 쿼리가 필요하면 `queries.sql`에 추가하고 워크스페이스에도 등록해야 합니다.
- `create_event`, `create_presentation` 같은 INSERT 쿼리는 프론트엔드의 폼과 이름·파라미터 순서가 일치해야 합니다.
- 스키마 변경(ALTER TABLE 등)은 이미 데이터가 있는 상태에서 조심스럽게 진행하세요.
